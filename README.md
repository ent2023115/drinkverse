# DrinkVerse 🥤

DrinkVerse is a responsive beverage recipe website created using HTML, CSS, Bootstrap, JavaScript, PHP and MySQL.

## Features

- Responsive home page
- Drink listing and recipes
- Juice and smoothie filtering
- User registration
- Secure password hashing
- User login and logout
- User dashboard
- Contact form
- Contact messages stored in MySQL
- Dynamic drink data from MySQL
- Bootstrap responsive design

## Technologies Used

- HTML5
- CSS3
- Bootstrap
- JavaScript
- PHP
- MySQL
- XAMPP

## Database

The project uses a MySQL database named:

`drinkverse`

The database contains:

- `users`
- `drinks`
- `messages`

The database export is included as:

`drinkverse.sql`

## How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the `drinkverse` folder into the XAMPP `htdocs` folder.
4. Open phpMyAdmin.
5. Create a database named `drinkverse`.
6. Import `drinkverse.sql`.
7. Open:

`http://localhost/drinkverse/`
